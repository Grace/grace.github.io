I build rule-driven controls that sit in the path of high-risk traffic. By day that means fraud logic on a transaction rules engine at a financial services firm, and carrying the pager for the money-movement services it guards. The rest of the time it means the same idea pointed at model traffic.

Things I've built

  • switchboard Go · LLM gateway
    One OpenAI-compatible endpoint in front of AWS Bedrock and on-device inference, for environments where the model provider is not your choice to make. Routes by model name, redacts content before it leaves the network, splits the Bedrock bill back out per team, and writes down what was sent.
  • paladin Go · integrity monitoring
    Watches the files an AI coding agent obeys — CLAUDE.md, .cursorrules, settings.json, skills — and reports drift, including the zero-width characters, bidi overrides and homoglyphs a reviewer's font will not draw.
  • @gracefulcode/paladin Node · supply chain
    Audits an npm package before you install it: install hooks, shipped agent instruction files, hidden characters, and whether it carries a provenance attestation. Published through trusted publishing, with no token in the repo.
